# 修改历史怎样读

这里保留本地修改说明和改动前的原件。当前操作从 [项目入口](../README.md) 和 [运行说明](../03_程序/运行说明.md) 开始，不从旧稿里的命令开始。

GitHub 只包含本说明。实际历史备份含旧代码、路径或客服数据，保留在本地，不随代码上传。以后共享代码的改动由 Git 提交记录保存；本地实验材料仍需要单独备份。

原电脑已有的记录依次为：01_文字说明改写、02_目录整理_20261023、03_运行路径修正_20261023、04_旧命令兼容_20261023、05_项目文档统一_20261023，以及带时间的06_GitHub上传准备目录。原首页索引保存在这次上传准备的修改前快照中。

含“修改前”的目录保留原始文字和路径，只用于对照。机器记录中的命令、参数、错误和程序副本也保留当时事实。用于核对程序搬家和入口的运行属于技术核对，不算新增独立研究样本。

每次修改说明要写清原因、改动范围和检查结果。研究规则另存版本，运行仍保留各自的规则副本和日志。代码提交记录不能代替实验记录。
