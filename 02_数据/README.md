# 怎样准备数据

原始客服对话不随代码上传。请从 [CSDS 项目](https://github.com/xiaolinAndy/CSDS) 了解数据获取办法和使用要求，再把训练数据放到项目内的 `02_数据/原始数据/train.json`。文件夹不存在时自行新建。

数据格式见 [官方字段说明](https://github.com/xiaolinAndy/CSDS/blob/main/utils/dataset_introduction.md)。需要的是符合该格式的实际数据文件，不是另存下来的网页。

原电脑现有的训练数据有9,101段，尚未在项目内放入验证集和测试集。获取其他版本时记录来源、日期和文件校验值，不能直接假定条数或内容相同。程序每次运行会记录输入文件指纹。

保持原始数据不变。新增数据另存文件，筛选结果放04_实验记录，人工判断放05_人工标注。本地历史中的目录整理记录保留了已有数据的来源和复制校验情况。

只用交接前原文确定当时的事项，不拿完整摘要或后文结果当参考答案。数据获取、使用和分享按原数据许可办理。
