# 人工标注从这里开始

先读 [标注怎么填](标注怎么填.md)。GitHub 仓库只保留方法说明，真实对话和填写中的工作文件保留在本地。

## 新运行怎样准备工作文件？

1. 筛选结束后，找到本次输出目录中的 `review_batch.md` 和 `review_batch.json`。前者用于阅读，后者包含同一批对话和待填写的标注字段。
2. 把 `review_batch.json` 复制到本目录，命名为 `annotations_pilot_v0.2.json`，供默认导出命令读取。若已经有这个文件，先另存新名字，使用 `-Reviews` 或 `--reviews` 指定，避免覆盖已有判断。
3. 可以直接填写 JSON 中的 review 部分；也可以先按标注说明用中文逐项记录，再整理进 JSON。中文记录和 JSON 不会自动同步。保留对话编号和来源运行目录，别把不同批次混在一起。
4. 合格数量足够后，再按 [运行说明](../03_程序/运行说明.md) 执行 finalize。`model_inputs.jsonl` 给模型，`gold_unresolved.jsonl` 保存人工参考答案，不给模型提前看。
