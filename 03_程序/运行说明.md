# 怎样运行这个项目

Python 命令需要 Python 3.10 或以上，不用安装第三方 Python 包；运行项目.ps1 入口另需 Windows PowerShell。先在项目根目录打开终端：这一层能看到 README.md、运行项目.ps1、01_研究说明等文件。从 GitHub 下载后，先按 [数据说明](../02_数据/README.md) 准备数据；真实数据和标注工作副本不随代码提供。

## 先检查入口，再开始筛选

```powershell
.\运行项目.ps1 -Action help
.\运行项目.ps1 -Action screen
```

入口会寻找可用的 Python 并检查版本。在原电脑上也可使用已有的 Codex Python；换电脑不依赖那个路径。如果自动寻找失败，明确指定自己的 Python：

```powershell
.\运行项目.ps1 -Action help -PythonPath "你的python.exe完整路径"
```

上面的引号内容是需要替换的示意。已安装 Python 且命令可用时，可以直接使用另一个入口：

```powershell
python .\csds_screen.py screen
```

这两个入口调用同一份03_程序中的代码。默认输入为02_数据/原始数据/train.json，输出为04_实验记录中新建的带时间目录；抽样数默认30，随机种子默认20261023。已有非空输出目录不会被覆盖。

## 从不同目录启动，脚本位置怎么写？

| 终端当前位置 | 启动方法 |
| --- | --- |
| 项目根目录 | `.\运行项目.ps1 -Action screen` |
| 03_程序文件夹 | `..\运行项目.ps1 -Action screen` |
| 其他目录 | 在 PowerShell 中用 `&` 调用运行项目.ps1的实际完整路径 |

程序的相对数据、标注、核验和输出路径，始终从项目根目录计算。脚本本身的位置仍需写正确。在03_程序里面不要再加一层03_程序。

## 调整抽样或输入文件

```powershell
.\运行项目.ps1 -Action screen -Sample 30 -Seed 20261023
```

需要另选输入时，直接调用 Python 入口。下面仍使用现有 train.json，只演示参数写法：

```powershell
python .\csds_screen.py screen --input "02_数据/原始数据/train.json" --sample 30 --seed 20261023
```

要指定输出，PowerShell入口用 `-Output`，Python入口用 `--output`。例如输出名可写 `04_实验记录/自定义运行名`，每次换新名字。省略输出则自动建新目录。

## 标注完成后再导出

先按 [标注目录说明](../05_人工标注/README.md) 建立工作副本，再按 [标注方法](../05_人工标注/标注怎么填.md) 把人工判断整理到 JSON。下面示例导出10段，只有至少10段被正确标成可纳入时才能完成：

```powershell
.\运行项目.ps1 -Action finalize -Count 10
```

Python入口的等价命令是：

```powershell
python .\csds_screen.py finalize --n 10
```

默认标注文件为05_人工标注/annotations_pilot_v0.2.json。换版本用 `-Reviews` 或 `--reviews` 指定。旧命令的相对 work 路径也兼容转到05_人工标注，并记录转换，但新说明统一使用当前目录名。

导出成功后，model_inputs.jsonl 给摘要模型；gold_unresolved.jsonl 留给评测，不给模型提前看；inputs/human_reviews.json 保存完整人工判断。合格不足或文件缺失会留下失败记录，不代表导出成功。

## 检查程序、记录和说明

```powershell
.\运行项目.ps1 -Action test
.\运行项目.ps1 -Action verify -Run "04_实验记录/02_第二次筛选_v0.2"
```

上面的核验目录是原电脑的已有运行，GitHub 下载的项目没有这份记录。请把 -Run 后面的目录换成自己真实生成的运行目录。核验检查文件有无变化，不判断人工标签在语义上是否正确。

手动修改标注或拷入运行记录后，更新目录和状态：

```powershell
.\运行项目.ps1 -Action docs
.\运行项目.ps1 -Action check-docs
```

更新说明不进行筛选或生成摘要。常规运行写入04_实验记录的直接子目录时，会自动更新目录表与状态页。

## 历史文件和当前程序的区别

当前代码在03_程序；根目录两个入口负责启动。每次实验 rules 文件夹里的代码、参数和旧路径用于追溯当次运行，不是最新使用方法。旧 experiments 输出在根目录 Python 兼容入口中转到04_实验记录；新命令直接使用当前目录或自动输出即可。
